## Descripción del Proyecto
Este proyecto desarrollado en Phyton, está direccionado directamente a la reserva de asientos de una sala de cine pequeña de 3 filas por 3 columnas. Este programa permite al usuario solicitar la ubicación exacta de una asiento mediante índices de fila y columna, registrar la reserva marcándola con "1", e imprimir el estado de la sala en formato matricial empleando bucles anidados.

## Indicadores de Estado
* **"0"**: Asiento libre
* **"1"**: Asiento reservado
